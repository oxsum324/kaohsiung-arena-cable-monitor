## 資料管線

`generate_cabledata_js.py` 讀取 8 台 FD404 CSV，換算絕對軸力並套用代表值過濾管線後，
輸出本報告所需之 `cabledata.js`（`window.CABLE_DATA`）：

1. **F_abs 換算**：`D=G(R-R0)+K(T-T0)`，`F_abs=F0+D×A×E/L_sensor`
2. **R0/T0 基準**：CSV 監測首 7 日穩定中位數／首 24 筆均值
3. **F0**：CSV metadata 之 Ch Offset（非 Excel 初值表，經比對後者曾發現配對錯位）
4. **代表值**：Layer0 物理範圍 → Layer1 F0×[60%,110%] → 固定 σ Z-score 濾波
   → Layer2 跨通道一致性(60%) → 取最接近 70% 基準值者為代表值
